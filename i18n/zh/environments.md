# 环境管理与本地存储

NERV 通过 uv 管理独立的 Python 虚拟环境。安装组件不会向系统 Python、Conda 环境或
LeRobot 训练环境安装软件包。使用 `nerv` 时，无需手动激活虚拟环境。

## NERV 安装哪些内容

发布安装器获取托管的 CPython 解释器和 uv，再由 uv 创建标准 Python 虚拟环境（venv）。
环境不加载系统 site-packages，各自拥有 Python 可执行文件和软件包目录。启动器根据保存的
绝对路径选择当前主程序；Runtime 通过自己的安装记录选择解释器。

| 环境 | 用途 |
|---|---|
| 主程序 | 网页、会话、模型连接和任务管理 |
| SO-101 Runtime | 按需安装 LeRobot、Feetech 和 ACT 推理依赖 |
| 仿真 | 按需安装仿真依赖和场景资源 |

ACT 策略共用兼容的 SO-101 Runtime，不为每个 checkpoint 重复创建环境。训练在 NERV
之外完成。后续 VLA 支持需要对应适配器和依赖检查，目前不安装任意 VLA 环境。

## 文件保存在哪里

默认根目录是 `~/.nerv`，Windows 上同样是用户主目录中的 `.nerv`。显式设置 `NERV_HOME`
可以选择其他根目录。“设置 → 系统与安装”和组件卡片中的“安装位置”显示当前实例实际使用的
根目录或环境路径。

| 相对路径 | 内容 |
|---|---|
| `envs/host/` | 按版本保存的主程序环境 |
| `envs/<component>/` | 各组件的独立环境 |
| `python/`、`bin/`、`bootstrap/` | 托管 Python、安装工具和启动入口 |
| `.cache/downloads/`、`.cache/releases/`、`.cache/uv/` | 下载记录、校验后的文件、发布资源和 uv 缓存 |
| `active.json`、`previous.json`、`runtimes/` | 当前主程序、回滚指向和组件安装记录 |
| `memory/`、`devices/`、`schemes/`、`artifacts/` | 会话历史、设备配置、控制方案和策略引用 |
| `credentials.json`、`vlm.json` | 私有凭据和模型设置 |
| `backups/` | 更新恢复快照 |

导入的模型目录和外部标定文件仍保留在原位置，NERV 保存其引用。删除 `.nerv` 不会删除这些
外部文件，但会删除 NERV 的配置和历史记录。清理前应先备份用户数据。

## 安装、更新和修复

NERV 根据主机系统和计算方案选择兼容发布清单，下载并校验文件，再创建新环境。依赖和
Runtime 检查通过后才启用。当前完整下载计划使用已校验的本地 wheel 安装，不在安装阶段
联网解析依赖。失败后可以复用缓存；服务器支持时，中断的文件可以继续下载。

组件安装和修复从组件页面操作。退出 NERV 后，使用 `nerv update` 更新，使用 `nerv rollback`
回滚。旧环境可能仍承担回滚用途，不能仅因出现新目录就删除。不要手动移动 venv 目录：解释器
链接和启动脚本可能含有绝对路径。更换根目录时，需要在目标位置重建环境，并在备份验证后迁移
用户数据、更新 Runtime 引用。

## 隔离的边界

虚拟环境隔离 Python 软件包，不是 Docker 容器、虚拟机或安全沙箱。NERV 仍以当前账户的文件
权限运行。USB 设备、相机、显存、端口和系统驱动由整台电脑共享。连接设备前，需要退出占用它
的其他程序。虚拟环境不能自动处理操作系统权限、显卡驱动或 WSL 的 USB 透传。

安装版主程序通过 Python 隔离模式启动，避免从工作目录或继承的 `PYTHONPATH` 加载模块。
Runtime 使用明确选择的解释器和经过筛选的进程环境。用户自行选择的外部适配器仍需单独检查
兼容性。

## 本地测试版

0.8.5 开发实现使用 `~/.nerv/profiles/preview` 保存预览版的配置、密钥、会话、设备档案和
个人资产。安装文件和兼容的依赖环境由共用存储根 `~/.nerv` 管理，可以复用已校验文件。
复制一次模型设置后，后续修改不会自动同步，也不会复制正式会话历史。

新版 `nerv preview` 命令在 8100 端口启动已安装的预览版。端口占用时会报错，不会停止其他
程序。公开的 0.8.1 尚不提供完整的 0.8.5 预览流程。开发源码、构建工具和安装包的关系见
[开发目录与安装环境](guides/development-and-installation.md)。
