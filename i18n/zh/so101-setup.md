# 接入已配置的 SO-101

NERV 0.8.4 是本地候选版。在“我的机器人”中打开 SO-101 设置。
准备一台已在 LeRobot 中完成电机配置和标定的标准 follower，保留标定 JSON 文件及对应的机器人 ID。

1. **检查电脑。** 查看系统、磁盘、下载工具和现有运行环境。需要处理时展开技术详情；在“系统与安装”中选择兼容的 CPU／NVIDIA 安装方案。
2. **安装运行组件。** 安装所需组件，或修复已有环境。安装页面显示目录、下载进度和可继续的任务。
3. **识别机械臂。** 连接 USB 和电源，确认检测到的串口。自动发现只读取系统设备信息，不打开电机连接。
4. **检查前置条件。** 选择标定目录和机器人 ID，点击“检查设备”。NERV 读取电机型号、位置模式和标定值，不写入电机 ID、波特率、零位、扭矩设置或标定寄存器。
5. **确认相机。** 预览顶部和腕部画面，确认角色与方向。标准配置使用两路不同的 OpenCV 相机，640 × 480、30 FPS。
6. **保存配置。** 返回机器人详情后单独连接。连接可能使电机带电；动作仍需操作者单独启用。

未找到文件，只表示 NERV 没找到标定，不能据此判断机械臂从未标定。
电机无响应、串口占用或权限不足时，检查保持“未完成”；读到明确不匹配的值时阻止继续。
请在 NERV 外按 [LeRobot SO-101 指南](https://huggingface.co/docs/lerobot/so101)处理，再选择正确文件并重新检查。本版没有自动标定按钮。

检查由独立进程执行，可随时取消。页面关闭后，检查会在租约到期时停止。
再次打开恢复配置；设备身份、标定内容或环境收据变化后需要重新检查。
旧档案保留，使用新适配器连接前需要补充前置检查证据。

Host、实机和仿真分别使用 `NERV_HOME`（默认 `~/.nerv`）中的独立环境。
ACT 策略共用已验证的实机推理环境；模型和外部标定文件仍按原路径只读引用。
NERV 不修改课程训练环境，也不安装系统显卡驱动或配置 USB 透传。
后续 VLA 插件可申请兼容的独立环境，本版不预装这些插件。

前置检查能力独立于动作协议进行版本管理，旧适配器缺少能力时需升级。
检查通过只表示满足接入条件，不代表抓取成功或完成实机验收。
