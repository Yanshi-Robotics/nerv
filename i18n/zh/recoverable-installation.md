# 可恢复安装

[English](../../guides/recoverable-installation.md) · [安装指南](github-install.md)

本功能属于尚未发布的 0.8.3 候选版。正式发布获准前，公开安装命令仍安装已发布版本。

## 选择环境

进入“设置 → 系统与安装”。NERV 检查主进程所在电脑的操作系统、进程架构、Python ABI、Linux libc、WSL／容器状态及 NVIDIA 驱动信息。浏览器所在电脑不参与安装包选择；检测失败与未发现显卡分别显示。

自动模式优先使用兼容的 CPU 方案；只有经过验证的 NVIDIA 清单和兼容驱动同时存在时，才推荐 NVIDIA 方案。CPU 与 CUDA 13.0 方案保持发布清单锁定的依赖版本。手动选择不能绕过已确认的架构、libc 或驱动冲突。Apple Silicon 需要 macOS 14 或更新系统，使用 CPU 路线，本版不承诺 MPS、AMD 或 Intel GPU 加速。当前锁定依赖不提供可安装的 Intel macOS 组合。缺少兼容二进制依赖的平台不会显示为可安装。

设置只影响后续安装。修改前先关闭机器人实例并暂停安装任务；已有环境和正在执行的任务保留原方案。更新已安装的 NVIDIA 环境时保留其计算方案，不自动改成 CPU。

命令行使用同一份设置：

```bash
nerv system
nerv system --compute cpu
nerv runtime plan lerobot0.6.1
nerv runtime install lerobot0.6.1
```

Shell 安装器接受 `--target linux-x86_64 --compute cpu`，也可选择兼容的 macOS 目标。PowerShell 接受 `-Target windows-x86_64 -Compute cpu`。两者都会核对当前进程架构。主程序始终使用 CPU 依赖。

## 查看进度

下载进度条包括所选方案的 Python、全部依赖 wheel 和组件资源。展开“下载文件”可查看单个文件、重试原因和下次重试时间。缓存命中计入总量，传输速度不包含任务开始前已有的字节。服务器要求重新下载某个文件时，进度可能回退。

下载、校验、创建环境、安装依赖和环境检查分别显示。下载达到 100% 后仍需完成安装检查，通过后才启用新环境。点击“安装位置”查看实际目录。日志随安装持续刷新；向上滚动查看历史时，不会强制跳回底部。

默认最多四个文件同时下载，每个文件一个连接，不额外限制总带宽。设置中可减少并发，或按字节／秒指定总上限。出现重试后，后续文件按单文件下载。每个文件最多自动重试五次，采用有上限的指数退避，累计等待不超过 15 分钟。连接超时为 60 秒，无数据超时为 180 秒；服务器给出的重试等待时间在累计预算内生效。

## 暂停与继续

短暂断网会自动重试。“暂停”和“取消”只停止本任务的传输，并保留有效片段。关闭或刷新网页不停止后台安装；退出 NERV 后，未完成任务保持暂停，下次打开不会自动下载。

从组件卡片继续，或使用安装任务 ID：

```bash
nerv runtime list
nerv runtime pause JOB_ID
nerv runtime resume JOB_ID
nerv runtime cancel JOB_ID
```

命令行安装期间保持运行，按 Ctrl+C 请求暂停。重复点击继续不会启动第二个工作进程。首次安装或更新中断后，使用同一数据目录和安装包再次运行原命令，复用已校验文件与有效片段。

续传会检查响应范围、文件长度和服务器提供的文件标识。服务器忽略范围请求时，安全重下该文件，不把完整响应接到旧片段后面。每个完整文件都必须通过 SHA-256 校验。证书、权限、磁盘空间和持续哈希错误会停止操作，不反复下载不可用文件。

## 存储与网络

`NERV_HOME` 默认为 `~/.nerv`。安装设置、系统报告、任务记录、独立环境和按 SHA-256 索引的下载缓存都保存在其中。已有 uv 缓存保持原样，不转换其私有下载片段。训练环境和策略原目录不变。

下载使用清单中的 GitHub、Python 包及 PyTorch 官方来源。代理可在设置中填写，也可在启动前提供标准代理环境变量。设置 API 不返回已保存的代理凭据；这些凭据不传给模型或 Runtime 管理命令。

全部文件校验通过后，uv 只安装明确指定的本地 wheel，禁用在线解析和隐式 Python 下载。环境检查通过后才切换引用。保留缓存后，可以离线重装同一方案；缺少文件的离线请求会停止并说明原因。

首次安装需要 curl（Windows 使用 curl.exe）、解压工具和 SHA-256 工具。Python 尚未可用时，平台引导脚本先通过 curl 续传并校验固定的 Python 与 uv，再运行 NERV 下载管理器。较小的入口脚本和清单单独获取。缺少系统工具时由操作者安装，NERV 不修改系统包管理器或驱动。

## 候选包目标

| 目标 | 主程序 | LeRobot | SO-101 仿真 |
|---|---|---|---|
| Linux x86-64、glibc 2.28+ | CPU | CPU／CUDA 13.0 | CPU 渲染 |
| Windows x86-64 | CPU | CPU／CUDA 13.0 | 清单已解析，执行未验证 |
| Apple Silicon、macOS 14+ | CPU | CPU | 清单已解析，执行未验证 |
| Intel macOS | 当前依赖不可安装 | 当前依赖不可安装 | 当前依赖不可安装 |

上表表示安装文件是否可用，不提升硬件支持等级。

## 验证范围

平台依赖解析、软件安装检查和实机验收是不同结果。Windows 或 macOS 清单可解析，不代表相机、USB 和电机已经验收；CUDA 元数据兼容不代表 GPU 推理已经成功。真实设备连接和动作仍由操作者执行，验收前应查看对应候选包的验证报告。
